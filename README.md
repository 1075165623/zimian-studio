# 粉色大肥鱼-文字PV

把歌词做成「文字 PV / 重击 MAD」的浏览器工坊：**词级编舞**、踩真实鼓点、内嵌中文字体，
在浏览器里直接排、直接预览、直接导出 MP4（WebCodecs）。
另附一个 **多轨剪辑台**：视频 / 图片 / 文字 / 音频都能像剪辑软件一样拖、切、套手法、混音、导出。

## 剪辑台（字面剪）

顶栏点 **✂ 剪辑台**（或地址加 `?edit=1`）进入：

- **多轨时间线**：拖拽 / 裁切 / 分割（S）/ 波纹删除 / 复制 / 框选 / 吸附片段与拍点 / 缩放 / 轨道静音隐藏锁定 / 标记 / 入出点。
- **四类素材**：文字、图片、视频、音频随便混排；视频可裁切、变速、套转场；音频多轨、波形、淡入淡出。
- **手法库 = 效果链**：文字片段可以同时叠 构图 + 入场 + 停留 + 退场 + 质感 + 背景 + 镜头 + 装饰，900+ 个手法点一下就用；另有 8 套成套预设和关键帧动画。
- **PV 层**：把主站当前工程整段带进时间线，再在上面加字幕 / 素材 / 音效，等于在成片上二次创作。
- **导出**：H.264 + AAC 的 MP4（可在入出点之间只导一段），进度可取消；也能导出当前帧 PNG。
- **存档**：自动存档（localStorage + IndexedDB）；「保存工程」打包成 `.zimedit.json`，素材一起带走。

细节见 [剪辑台说明.md](剪辑台说明.md)。


## 这一版换掉了什么

- **编排语法**：从「每句歌词抽一套 入场+停留+退场」改成「每个词一脚踩在音节上」的编舞。
  10 个动作：重击入场、逐字硬切、穿字、遮罩条、老虎机滚字、字距爆开、残影堆叠、
  切片错位、描边/实心/反白闪切、匹配切。默认没有退场，下一镜硬切顶掉。
- **整句版面**：主歌/预副歌/桥段恢复整句构图（10 种：左主词、上下夹击、阶梯、竖排、裁切巨字、重叠、标签、网格、中轴对称、底字锚），
  词按音节累积出现，当前词高亮，已唱词保留为次级亮度。副歌最重的短句仍保留单词重击。
- **场景层**：9 个克制背景（歌词墙 / 色块 / 网格 / 节拍圆 / 速度线 / 时间码 / 手绘线 / 漏光 / 柔光）、
  6 个句级镜头、6 个句间转场；背景读绝对时间，不会随词切重置。
- **动作库**：在原来 10 个之外补了上滚揭示、斜缝、弹簧落下、缩成锚点、手绘圈、下划线、字符翻转、长音拉伸。
- **嵌套舞台**：有素材的行不再把视频当背景板，而是进「左照片右字 / 竖窗 / 横幅 / 满幅 scrim / 偏移卡」五种舞台；
  舞台整行稳定，词切只在它的文字区里动。
- **驱动**：词级时间（增强型 LRC / 逐词时间表 / 按字数和标点估算）+ 真实起音检测
  （底鼓 / 军鼓 / 高频，100 Hz 包络），重击和闪白踩真鼓点，不踩匀速 BPM 网格。
- **段落**：主歌安静、预副歌逐词切、副歌最大、间奏留白；重复副歌复用同一套动作。
- **渲染**：180° 快门的子帧动态模糊（只给快速动作）、2 コマ打ち 默认 12 张/秒、
  1–2 帧的闪白 / 反白、轻颗粒 / 轻色差 / 微抖。
- **中文排版**：分词驱动，虚词小一档、情感词大一档；竖排不再硬套日文假名规则。
- **字体**：内嵌子集化 woff2（Noto Sans/Serif SC、站酷系、霞鹜文楷、马善政、龙藏），
  换电脑 / 断网也保持同一副字；单文件版用 base64 内嵌。
- **一键成片**：不再先选模板，直接从完整高级手法库里重新编排（构图 / 入场 / 装饰 / 背景 / 镜头 / 转场）。

## 开发与发布

```
node tools/build_publish.mjs
```

会生成 `dist/site/`（静态站点）和 `dist/粉色大肥鱼-文字PV.html`（单文件，字体已内嵌）。
根目录就是 GitHub Pages 的发布目录，提交并推送 `main` 即可更新线上版本。
