# TCG-PV工厂

把歌词做成「文字 PV」风格的动态字幕：885 个手法、素材自动印进信纸 / 拍立得 / 明信片，
在浏览器里直接排、直接预览、直接导出 MP4（WebCodecs）。

- 在线地址：**https://1075165623.github.io/zimian-studio/**
- 仓库：https://github.com/1075165623/zimian-studio
- 本地使用：双击 `dist/TCG-PV工厂.html`（单文件版，离线可用）
- 用法说明：[使用说明.md](使用说明.md)
- 发布 / 更新：[部署说明.md](部署说明.md)

> 改完代码想上线：双击 `发布.cmd`（提交 + 推送），GitHub Pages 一分钟内自动更新。

基于 [JIZURA](https://github.com/852wa/JIZURA)（MIT，© 2026 hakoniwa）的引擎改造，界面与编排重写。
